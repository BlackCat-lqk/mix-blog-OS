# mix-blog-OS

基于 Vue 3、TypeScript 和 Vite 的桌面应用，目前保留：

- 设置：系统壁纸、自定义壁纸、账户资料和头像管理。
- 登录：邮箱登录、注册、登录状态持久化和退出登录。
- 音乐：本地与在线曲库、搜索、播放控制、循环模式、封面和同步歌词。
- 图库：服务端图集、图片和视频，支持图集切换、搜索、类型筛选与分页。
- 导航：从服务端分类树加载一级/二级分类及网站。
- 基础界面：桌面和应用窗口。
- 控制面板：仅管理员登录后显示，可管理用户、音乐、图集、媒体、导航分类和网站。

双击桌面的「设置」图标打开或恢复最小化的窗口，点击左侧账户区域打开登录弹窗。

邮箱注册填写邮箱、邮箱验证码、用户名和密码：先填写有效邮箱并点击“发送验证码”，再输入邮件中的 6 位数字。验证码 10 分钟有效，同一邮箱每次发送后冷却 60 秒，倒计时在刷新和多个标签页间同步。校验错误保留注册输入；后端独立校验验证码、过期时间和一次性使用，缺失验证码不能注册。后端需先配置 QQ SMTP 发件邮箱和授权码，见 `mix-blog-server/README.md`。

左侧桌面状态栏分为三部分：顶部可返回桌面或打开全部应用总览；中间显示已打开的应用，点击可切换、恢复或最小化当前窗口；底部直接进入个性化设置。全部应用总览覆盖整个桌面，提供顶部搜索和应用图标网格；支持中英文名称搜索、回车打开首个结果、Esc 或点击空白处退出，退出后恢复原窗口状态。总览中点击状态栏的应用会直接打开或恢复窗口。返回桌面会最小化所有窗口并保留应用状态。最大化窗口紧贴状态栏右边缘，普通窗口可以拖到状态栏下方，状态栏保持最高层级。

## 窗口组件

项目的接口声明统一放在 `src/tsInterface/index.ts`，各模块通过 `import type` 引用。

- `src/components/OsWindow/index.vue`：公共窗口外壳，提供 `sidebar` 和默认内容插槽，通过 `v-model:minimized` 管理最小化，`visible` 独立控制总览等临时隐藏，向外发送 `activate`、`close` 事件。应用通过此组件统一获得拖拽、缩放、最大化、还原和窗口过渡。
- `src/components/OsWindow/WindowSidebar.vue`：窗口侧边栏子组件，通过 `items` 和 `v-model` 控制导航，`header` 插槽用于放置账户等应用内容。
- `src/components/OsWindow/useWindowGeometry.ts`：封装拖拽、缩放、最大化和位置状态，不依赖具体应用。
- `src/components/OsWindow/useWindowMotion.ts`：设置、音乐及后续应用统一使用 200ms 窗口过渡。最小化收回到对应状态栏图标，恢复时从图标展开；最大化与还原使用 FLIP 缩放过渡，保留原位置和大小。拖拽、缩放及桌面总览切换不会附带过渡；减少动态效果模式下直接切换。
- `src/views/Setting/IndexView.vue`：组合窗口、侧边栏与设置内容，维护设置业务和登录状态。应用入口统一注册在 `src/config/index.ts`。

## 音乐应用

双击桌面的「音乐」或从全部应用中打开。左侧菜单切换本地和在线，内容区左侧显示列表与搜索，右侧显示当前歌曲、封面、歌词和播放控件。在线页面调用 `/api/music`，提供歌曲/歌手搜索、分页和刷新；点击歌曲后使用后端音频地址播放，并按需加载 `lyricsUrl` 的歌词文件。歌词失败可单独重试，不影响音频播放。

- 点击「添加音乐」可批量选择音频。播放格式以浏览器支持为准；列表标题默认使用文件名，`歌手 - 歌名.mp3` 会自动拆分歌手和歌名。
- 同时选择与音频同名的 `.lrc` / `.txt` 和封面图片，可自动关联；也可点击当前歌曲的封面或「导入歌词」单独选择。暂不解析音频内嵌标签。
- LRC 支持多时间标签、毫秒时间和 offset 偏移，当前歌词自动高亮并居中，点击歌词可跳转；无时间标签时按纯文本显示。
- 支持播放、暂停、上一首、下一首、进度拖动和音量调节；播放模式按钮依次切换列表循环、单曲循环、随机播放。随机模式在一轮中避免重复，上一首返回已播放记录。本地与在线队列独立；本地搜索只筛选显示，在线搜索和分页更新候选队列并保留正在播放的歌曲。
- 本地文件只在浏览器使用，关闭应用后需重新添加；在线歌曲保存在后端，刷新后仍可查询。最小化、返回桌面或切换来源不停止播放，关闭音乐应用时停止音频、取消歌词请求并释放本地对象 URL。

`src/views/Music/useMusicPlayer.ts` 管理音频、队列与歌词，`lyrics.ts` 解析歌词，`components/` 负责列表和播放器界面。`MusicTrack.source` 区分本地与在线来源；在线歌曲的封面、歌词通过管理页面维护，本地歌曲仍可直接导入配套文件。外部歌词地址需要允许浏览器跨域读取。

## 图库与导航

图库启动时读取 `/api/gallery/albums`，完整加载分页图集供侧栏选择；媒体通过 `/api/gallery/media` 按当前图集、关键词和图片/视频类型分页查询。未提供缩略图的图片使用原图预览，视频支持原生播放控件。导航读取 `/api/navigation/tree`，按一级分类和二级分类展示网站卡片；无图标或加载失败时显示网站名首字。两者均支持刷新、失败重试和空状态，关闭窗口后取消未完成请求，加载失败时不回退到示例数据。

## 控制面板

管理员登录后可从桌面或全部应用打开「控制面板」。入口同时检查登录标志、token 和 `admin` 角色；普通用户和未登录用户均隐藏入口并阻止打开。退出登录、角色降为普通用户或接口返回 401 后移除入口、关闭窗口并清空面板内的数据。

面板内容和所有管理操作仅管理员可用。用户管理提供用户列表、用户名/邮箱搜索、状态筛选、分页、新增、编辑资料、设置角色与状态、重置密码及删除确认。当前登录账号不能删除，也不能在此修改自己的角色与状态。表单复用现有用户名、邮箱和密码校验，编辑时密码留空表示不修改。只有接口成功后才显示操作成功；列表请求失败支持重试，保存失败保留表单内容。

用户及内容接口已对接同级目录 `mix-blog-server`。用户管理接口位于 `src/server/userManagement.ts`，约定如下：

| 方法 | 路径（相对 `/api`） | 参数 / 请求体 |
| --- | --- | --- |
| GET | `/user/list` | `page`（从 1 开始）、`pageSize`、`keyword`（用户名/邮箱）、`status`（空值为全部） |
| POST | `/user/create` | `userName`、`email`、`password`、`role`、`status`、`desc` |
| PUT | `/user/:id` | 同上，`password` 可省略，省略时保留原密码 |
| DELETE | `/user/:id` | URL 中的用户 `_id` |

角色为 `user`（普通用户）、`admin`（管理员）；状态为 `active`（正常）、`disabled`（已禁用）。列表中的其他角色/状态值按原值展示。列表响应沿用现有请求封装的嵌套格式：

```json
{
  "data": {
    "code": 200,
    "message": "操作成功",
    "data": {
      "list": [
        {
          "_id": "user-id",
          "userName": "示例用户",
          "email": "user@example.com",
          "role": "user",
          "status": "active",
          "desc": "",
          "createdAt": "2026-11-20T00:00:00.000Z"
        }
      ],
      "total": 1
    }
  }
}
```

新增、编辑和删除成功返回 `{ "data": { "code": 200, "data": null } }`；失败信息放在 `data.message`。后端独立校验 Bearer token、管理员权限、唯一邮箱、字段有效性及当前账号保护。401 清除登录状态；403 显示权限错误。

内容管理入口和请求路径如下，集合路径支持 GET 列表和 POST 新增，`/:id` 支持 PUT 编辑和 DELETE 删除：

| 面板菜单 | 管理路径 |
| --- | --- |
| 音乐管理 | `/api/admin/music` |
| 图集管理 | `/api/admin/gallery/albums` |
| 媒体管理 | `/api/admin/gallery/media` |
| 导航分类 | `/api/admin/navigation/categories` |
| 网站管理 | `/api/admin/navigation/sites` |

管理列表支持关键词、状态、关联分类筛选及分页；表单支持外部 HTTP/HTTPS 地址或文件上传，以及描述、排序和状态。音频最大 100 MB，图集封面、图库原图和缩略图最大 50 MB，音乐封面和网站图标最大 5 MB，UTF-8 歌词最大 1 MB，视频最大 100 MB。上传音频时可留空歌曲名和歌手，后端会尝试从元数据补齐曲目信息、缺失封面与歌词；手动填写和上传优先，无元数据时使用文件名和“未知歌手”。编辑时留空可移除可选封面、缩略图和歌词；不替换的本地文件地址保留原值。切换菜单会取消未完成请求并清理当前表单；保存失败保留输入及选中的文件，重复点击不会重复提交。

新增媒体前先创建图集，新增网站前先创建一级和二级分类。非空图集/分类删除时展示后端 409 错误并保留确认框；先移动或删除其中内容再删除父级。管理成功后列表自动刷新，已打开的应用可点击“刷新”获取新内容。完整字段和请求示例见后端 `docs/content-api.md`。

运行 `npm run test:users` 验证用户管理，`npm run test:content` 验证内容 API、请求竞态、表单上传校验、失败保留和分页回退，`npm run test:music` 验证本地/在线队列和歌词，`npm run test:registration` 验证邮箱验证码、倒计时、取消和注册提交。

## 页面路由

根组件 `src/App.vue` 只渲染路由出口，桌面位于 `src/views/Desktop/IndexView.vue`。桌面、独立登录页和错误页均通过路由动态导入。错误页共用 `src/views/Error/IndexView.vue`，按路由传入的状态码显示内容。

- `/403`（`error-403`）：无访问权限。
- `/404`（`error-404`）：页面不存在；所有未匹配的地址重定向至此。
- `/500`（`error-500`）：服务异常。
- `/login`：独立登录页面，关闭或登录成功后返回桌面。

业务中可使用 `router.replace({ name: 'error-403' })` 或 `router.replace({ name: 'error-500' })` 跳转。接口表单中的错误仍由原有逻辑处理。

## 开发

Node.js 版本要求：`^20.19.0 || >=22.12.0`。

```sh
npm ci
npm run dev
```

默认不注入 Vue DevTools 调试面板；需要时运行 `npm run dev:tools`。

开发环境将 `/api` 和 `/uploads` 代理至 `http://localhost:3000`。请同时启动 `mix-blog-server`；管理功能需要管理员账号，首个管理员设置方法见后端 README。

个性化设置中「浏览照片」下方可启用必应在线壁纸，读取 `images[0].url` 并拼接 `https://www.bing.com` 作为桌面背景。开关状态会保存，刷新后重新获取今日壁纸；关闭开关恢复原壁纸，手动选择或上传图片会关闭必应壁纸。请求失败时保留当前背景，可点击「重试」。

必应的 JSON 接口不允许浏览器跨域读取，Vite 开发与预览服务通过 `/bing/HPImageArchive.aspx` 代理请求。生产部署也需要配置此代理，例如 nginx：

```nginx
location = /bing/HPImageArchive.aspx {
    proxy_pass https://www.bing.com/HPImageArchive.aspx;
    proxy_set_header Host www.bing.com;
    proxy_ssl_server_name on;
}
```

## Lighthouse 评测

使用生产构建评测，避免将 Vite 的模块转换、热更新和调试脚本计入页面性能：

```sh
npm run build
npm run preview -- --host 127.0.0.1
```

在 Chrome 无痕窗口中打开命令输出的地址，再运行 Lighthouse。报告中提示的 IndexedDB 存储数据会影响壁纸加载；比较前后结果时应使用相同的设备、限速和壁纸数据。

桌面首屏只加载基础界面，设置、音乐和登录表单在打开时加载。页面提供中文语言标记、主内容区域、描述信息及有效的 `robots.txt`。
